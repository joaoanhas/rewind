# Rewind

Jogo de festa para jogar no browser: grava uma palavra, ouve-a ao contrário, imita o som e inverte a imitação para adivinhar.

- Partida livre ou torneio (2 a 16 jogadores, eliminatórias com passagem direta, melhor de 1, 3 ou 5)
- Reprodução a 1x, 0,75x e 0,5x

Jogar: https://joaoanhas.github.io/rewind/
